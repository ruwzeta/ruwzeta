<details>
<summary><b>🧠 What I build with LLMs</b> (click to expand)</summary>
<br/>

- **Retrieval-Augmented Generation (RAG):** pipelines over healthcare and enterprise documents with chunking, hybrid search, reranking and grounded answer generation
- **Agentic workflows:** tool use, function calling and multi-step planning with LangGraph, LlamaIndex, CrewAI, the OpenAI Agents SDK and the Claude Agent SDK
- **Structured extraction & enrichment:** pulling structured data out of unstructured clinical and operational text using JSON mode and constrained decoding
- **Evals & guardrails:** offline benchmarks, regression tests, prompt versioning and red-team prompts for safety
- **Fine-tuning & adaptation:** LoRA/QLoRA on open-weight models (Llama, Mistral, Qwen) for domain-specific tasks
- **Voice & multimodal:** experiments combining Whisper, vision models and TTS

</details>
